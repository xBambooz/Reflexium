Stage 01
Reflex sleep
The driver sleeps the CPU until the GPU is ready to receive new work, preventing frames from piling up in the driver queue.
Minecraft.run() vkLatencySleepNV
Stage 02
Input poll
User mouse and keyboard events are polled immediately after waking so the game processes the freshest player inputs.
RenderSystem.pollEvents() SDLEventHandler
Stage 03
Simulation tick
The game updates player movement, world physics, and entity logic based on the freshly polled inputs.
Minecraft.tick() Minecraft.runTick()
Stage 04 8 SUB-STEPS
Render submission: world, hand, motion vectors, upscaling, GUI
The world renders at reduced resolution, generates motion vectors, upscales to display resolution, and draws the full-resolution GUI.
Step A Target swap Main target textures swapped to low-res target before level rendering.
Step B World with jitter Terrain and mobs drawn with Halton sub-pixel camera jitter offset.
Step C World depth copy World depth copied before vanilla clears depth for the hand pass.
Step D Hand with jitter First-person hand drawn into low-res target with matching camera jitter.
Step E Motion vectors Camera reprojection plus visible object velocity; hand given zero motion.
Step F Post effects Vanilla post-processing shaders run at reduced resolution.
Step G Upscale evaluation DLSS or FSR reconstructs sharp display-resolution image from low-res inputs.
Step H Target restore & GUI Textures swapped back; HUD, crosshair, and chat draw at native resolution.
GameRenderer.render() UpscalingRenderer: beforeLevel -> captureWorldDepth -> motionPass -> evaluate -> afterPostEffects
Stage 05
Queue submit
Vulkan command buffers are tagged with a monotonic present ID and submitted to the GPU queue.
VulkanQueue.Submission VkLatencySubmissionPresentIdNV
Stage 06
Swapchain present
The finished display-resolution frame is handed over to the display hardware for presentation.
VulkanGpuSurface.present() VkPresentIdKHR -> vkQueuePresentKHR

Driver frame latency span
Measured by the driver from INPUT_SAMPLE to PRESENT_END: Frame latency = presentEndTimeUs - inputSampleTimeUs. Timing queries run continuously through vkGetLatencyTimingsNV so latency data is available in F3 even when Reflex is toggled Off.
