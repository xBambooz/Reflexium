Native C++ bridges Foreign Function & Memory API
reflexium_ngx.dll → NVIDIA NGX
Static nvsdk_ngx_s.lib bridge
Bridges Java FFM to NVIDIA NGX C API on Minecraft's Vulkan device; loads nvngx_dlss.dll auto-downloaded by DlssRuntimeInstaller.

FidelityFX SDK 1.1.4 bridge
Bridges Java FFM to amd_fidelityfx_vk.dll; provides universal FSR 3.1 temporal upscaling and RCAS sharpening on any Vulkan GPU.
